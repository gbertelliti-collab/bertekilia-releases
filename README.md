# Bertekilia — downloads

Este repositório guarda só os pacotes (`.zip`) de cada versão publicada do **Bertekilia**, o jogo de
estratégia em tempo real para Windows. O código não fica aqui.

- Página oficial, com telas, vídeos e instruções: <https://bertekilia.mgcapitaltech.com.br>
- Baixe a versão atual em **Releases** (o botão do site aponta para cá). Cada release traz o
  tamanho e o SHA-256 do zip para conferência.
- Para jogar: extraia o zip (sai uma pasta `Bertekilia/`) e abra `Bertekilia.exe`.
